# Changelog — Free-Tier Movements

Dated tracker of tier changes across the ecosystem. Tightenings and expansions both belong here.

## 2026

- **Jul** — Straico shut down (Jul 22)
- **Jun** — Cursor closed free student year to new signups (Jun 25) · Gemini CLI free OAuth tier deprecated for non-enterprise (Jun 18) · Windsurf student offer ended with Devin Desktop rebrand
- **May** — Amazon Q Developer discontinued for new signups (May 15)
- **Apr** — GitHub Copilot Pro student signups paused (Apr 20) · Qwen free OAuth discontinued (Apr 15)
- **Mar** — Google made Gemini Code Assist free for individuals: 180K completions/mo, 240 chat/day · Anthropic introduced limited free API trial credits, replacing its no-free-tier policy
- **Feb** — GitHub Copilot Free expanded premium-request allowance · Brave Search API free tier removed
- **Jan** — Phind shut down (Jan 16) · Gemini free 12-month student promo closed · Flagship reasoning models broadly restricted to paid tiers across OpenAI / Anthropic / Google
- **Early 2026** — OpenRouter cut free-model RPD from 200 to 50 for zero-credit accounts

## 2025

- **Dec** — Google cut Gemini API free-tier limits 50–80%
- **Jul 15** — AWS replaced the 12-month free tier with the credit-based Free Plan ($100 + $100 tasks, 6-month auto-close) for new accounts
- **Apr** — Tabnine sunset its free tier
